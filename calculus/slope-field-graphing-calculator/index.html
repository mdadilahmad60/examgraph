About this tool

Updated November 2026 · Free, no sign-up

Draw a slope field for dy/dx = f(x, y) and a solution curve through any starting point. Free online slope field grapher for AP Calculus BC.

A slope field is a picture of a differential equation. At each point (x, y) a short segment shows the slope dy/dx that the equation prescribes, and a solution curve is any curve that follows those segments. Slope fields appear in AP Calculus BC and in college differential equations because they let you describe solutions without solving the equation.

Type dy/dx = followed by an expression in x and y and the grapher draws a field of short segments, each with the slope the equation gives at that point. Add a starting point after a comma, as in dy/dx = x - y, y(0) = 1, and it also draws the solution curve through that point, in both directions, computed numerically with the Runge-Kutta method. The default does exactly that: watch the solution settle onto the line y = x - 1. A letter such as k in dy/dx = k*y becomes a slider, and the segments sit on a grid of 1, 2 or 5 units (like the grid lines), so zooming in adds more segments and zooming out spaces them wider.

  • Write dy/dx = f(x, y); the right side can use x, y and sliders.
  • Add , y(x0) = y0 to draw the solution curve through that starting point.
  • Each segment has the true slope: where it is flat the slope is 0, and where it is vertical the slope is undefined.
  • Solution curves follow the segments and never cross one another.
  • Zoom in for a denser field or out for a wider one: the spacing follows the grid lines.
  • The solution curve is a numerical approximation, so use it to check a sketch or a hand solution.

Try these examples

  • dy/dx = y, y(0) = 1Exponential growth: the solution is e^x
  • dy/dx = x*y, y(0) = 1Slope depends on both x and y; the solution is e^(x^2/2)
  • dy/dx = y*(1 - y/4), y(0) = 1Logistic growth leveling off at the equilibrium y = 4
  • dy/dx = k*y, y(0) = 1Slider k: growth for k > 0 and decay for k < 0
  • dy/dx = -x/y, y(0) = 2The solution is the upper half of the circle x^2 + y^2 = 4

Solved examples

Exponential growth from dy/dx = y

Problem. Solve dy/dx = y with y(0) = 1 and read the slope field.

  1. Every slope equals the y-value, so the segments are flat on y = 0 and steeper higher up.
  2. Separate variables: dy/y = dx, so ln|y| = x + C, and y = Ce^x.
  3. Use y(0) = 1: C = 1, so y = e^x.
  4. Check against the field: at (1, e) the slope should be e ≈ 2.718, and the solution passes through that point.

Answer. y = e^x. The solution curve follows the segments and has y(1) = e ≈ 2.718. Graph it in the calculator

A circle from dy/dx = −x/y

Problem. Solve dy/dx = −x/y with y(0) = 2.

  1. Separate variables: y dy = −x dx.
  2. Integrate: y²/2 = −x²/2 + C, so x² + y² = 2C.
  3. Use y(0) = 2: 0 + 4 = 2C, so x² + y² = 4.
  4. Since y(0) = 2 is positive, the solution is the upper half: y = √(4 − x²). At (1, √3) the slope is −1/√3 ≈ −0.577.

Answer. y = √(4 − x²), the upper half of a circle of radius 2. The slope segments are always perpendicular to the radius. Graph it in the calculator

How to use the Slope Field & Solution Curve Grapher

  • Type an equation. Write it in terms of x, for example x^2 - 4 or 2x + 1. Circles, ellipses and inequalities work too: try x^2 + y^2 = 9 or y > 2x + 1 (shaded). On a phone, tap the equation box and use the built-in math keyboard for powers, roots, fractions and trig.
  • Compare curves. Tap + to add more equations. Intersections, roots, intercepts and turning points are marked automatically, and you can tap any entry under Key points to jump to it.
  • Use sliders. Any extra letter becomes a slider, so a*x^2 + b*x + c lets you drag a, b and c.
  • Move around. Drag to pan, pinch or scroll to zoom, or use the + / − buttons. The home button resets the view and the corner button opens a full-screen graph.
  • Plot points and fit a regression. Type a point such as (2, 5) or a list like (1, 2), (2, 4), (3, 5). For real data, open Data table & regression, paste x, y pairs and pick linear, quadratic, cubic, exponential, power or logarithmic: the best-fit equation, R² and a prediction box appear instantly.
  • Degrees or radians. Tap RAD / DEG beside the equations to switch angle mode.
  • Name, share or save. Edit the graph title above the plot. Settings lets you download a PNG or JPG, or open a print-ready page to save as PDF. The share button copies a link that reopens your equations and graph title.
  • Practice for tests. Turn on US Exam Mode in Settings to lock key-point hints and tooltips, like a real testing calculator.

Frequently asked questions

Does this tool draw a slope field?

Yes. Type dy/dx = and an expression in x and y, such as dy/dx = x - y. Short segments show the slope at each point, and a starting point such as y(0) = 1 adds the solution curve through it.

How do I find the solution through a given point?

Add the point after a comma: dy/dx = y, y(0) = 2. The solution curve is drawn through it in both directions. To do it by hand, find the general solution with a constant C and substitute the point to solve for C.

What is an equilibrium solution?

It is a constant solution where the slope is zero everywhere on the line. For dy/dx = y*(1 - y/4), y = 0 and y = 4 are equilibria, and you can see flat segments along both lines.

Why do solution curves never cross?

If two solutions met at a point, the equation would give two different slopes there, contradicting the single slope at each point. This is why solution curves fan out in order.

How do I match a slope field to its equation?

Check where the slopes are zero, where they are steep and whether they depend on x, y or both. Then type your guess and compare the picture with the one in your problem.
