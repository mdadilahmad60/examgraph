How to graph a parabola: find the vertex, axis of symmetry, intercepts and direction, then check it on a free online graphing calculator.

A parabola is the graph of a quadratic function y = ax^2 + bx + c. Every parabola has a vertex (its highest or lowest point), an axis of symmetry through the vertex, and at most two x-intercepts. Finding these four things is enough to sketch an accurate graph.

First decide the direction: if a is positive the parabola opens up, and if a is negative it opens down. Then find the vertex using x = -b/(2a) and substitute to get y. Next find the intercepts: set x = 0 for the y-intercept and solve ax^2 + bx + c = 0 for the roots.

Plot the vertex, the intercepts and one mirrored point on the other side of the axis, then draw a smooth curve through them. You can graph the equation here to check your sketch, and use the quadratic graphing calculator for roots and the discriminant.

  • Check the sign of a to see which way it opens.
  • Vertex: x = -b/(2a), then find y.
  • Intercepts: y-intercept is c; solve for roots.
  • Plot a mirrored point and draw a smooth curve.

Solved examples

An upward parabola

Problem. Graph y = x^2 - 6x + 8.

  1. a = 1 > 0, so it opens up.
  2. Vertex: x = 6/2 = 3 and y = 9 - 18 + 8 = -1, so (3, -1).
  3. Roots: (x - 2)(x - 4) = 0, so x = 2 and x = 4. The y-intercept is 8.

Answer. Vertex (3, -1), roots 2 and 4, y-intercept (0, 8). Graph it in the calculator

A downward parabola

Problem. Graph y = -2x^2 + 4x + 6.

  1. a = -2 < 0, so it opens down.
  2. Vertex: x = -4/(2(-2)) = 1 and y = -2 + 4 + 6 = 8, so (1, 8).
  3. Roots: -2(x^2 - 2x - 3) = 0, so (x - 3)(x + 1) = 0 and x = 3 or x = -1. The y-intercept is 6.

Answer. Vertex (1, 8), roots -1 and 3, y-intercept (0, 6). Graph it in the calculator

Vertex form to a graph

Problem. Graph y = -(x + 2)^2 + 5.

  1. In vertex form the vertex is (-2, 5). The coefficient -1 means it opens down.
  2. y-intercept: -(2)^2 + 5 = 1.
  3. Roots: (x + 2)^2 = 5, so x = -2 + sqrt(5) or -2 - sqrt(5), about 0.236 and -4.236.

Answer. Vertex (-2, 5), y-intercept (0, 1), roots about -4.236 and 0.236. Graph it in the calculator

Common mistakes

  • Using x = b/(2a) instead of x = -b/(2a), which puts the vertex on the wrong side.
  • Forgetting that the vertex y-value comes from substituting, not from c.
  • Drawing a pointy bottom. A parabola is smooth, and it keeps getting wider the farther it goes.
  • Skipping the mirror point, which makes the sketch lopsided.

Quick checks for your sketch

The graph should be symmetric about the axis of symmetry. The y-intercept and its mirror point should be at the same height. If the parabola opens up, the vertex is the lowest point; if it opens down, it is the highest.

How to use the How to Graph a Parabola Step by Step

  • Find the direction. Positive a opens up; negative a opens down.
  • Find the vertex. x = -b/(2a), then substitute for y.
  • Find the intercepts. y-intercept is c; solve for the roots.
  • Plot and draw. Add a mirror point, then draw a smooth curve.

Frequently asked questions

How do I find the axis of symmetry?

It is the vertical line through the vertex, x = -b/(2a). Points on the parabola at equal distances either side of it have equal heights.

How many points do I need to plot?

The vertex, the y-intercept and its mirror image give three points. Add the roots when they exist for a tidy sketch.

What if there are no x-intercepts?

If the discriminant b^2 - 4ac is negative the parabola never touches the x-axis. The vertex is above the axis when it opens up, or below when it opens down.

What is the difference between standard and vertex form?

Standard form y = ax^2 + bx + c shows the y-intercept. Vertex form y = a(x - h)^2 + k shows the vertex (h, k) directly.

How do I know if a parabola is wide or narrow?

Compare the absolute value of a with 1. A value above 1 makes it narrower, and a value between 0 and 1 makes it wider.
